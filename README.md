Программа для отображения цветных полос на шкале частот. Полосы автоматически генерируются, не пересекаются и имеют случайную штриховку.

## Возможности

- ✅ Автоматическая генерация полос с проверкой пересечений
- ✅ Случайные цвета и паттерны штриховки
- ✅ Автоудаление старых полос (хранится не более 10)
- ✅ Масштабирование и перетаскивание (мышкой)
- ✅ Клик по полосе - подсветка и всплывающая информация
- ✅ Автоматическая прозрачность при наложении полос

## Алгоритм
- Каждые 200 мс генерируется новая полоса
- Алгоритм ищет свободное место (300-500 МГц)
- Если полос > 10 - удаляется самая старая
- Каждая полоса получает случайный паттерн штриховки
- При наложении полосы становятся прозрачнее
